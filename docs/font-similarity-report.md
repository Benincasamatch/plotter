# 字体笔画相似性分析

分析 304 个字体文件，抽样 128 个常用汉字；以 blood8 真迹系列的 10 对非重复变体作为距离参照。

评分基于归一化实际笔画的墨迹位置、书写路径顺序和抬笔分段，不代表同一作者的概率。文件名仅用于建立参照组，整个库的近邻搜索使用笔画数据。

推荐阈值采用参照组距离的第 90 百分位：0.26882，对应评分 82/100。疑似重复文件对使用全部共同字的原始字形记录复核，发现 12 对高度重复/子集关系；不将重复项作为混写变化来源。

全库有效字体配对的相似评分中位数为 78.9，第 95 百分位为 82.4。推荐组合要求三者两两接近，并保留可测得的字形变化。
