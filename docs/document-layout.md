# 多页文档、笔记与表格模式

笔记模式默认“固定每页行数 · 自动字高”，也可选择“固定字高 · 自动行数”。松紧滑块表示行距与字高的比值（1–4 倍）：固定行数时，行距为可写高度 ÷ 行数，字高为行距 ÷ 松紧；固定字高时，行距为字高 × 松紧，行数向下取整。自动结果超出 2–20 mm 或 1–200 行时明确提示，不静默截断。预设和文档保存这两个联动设置；旧 API 不提供 `line_sizing` 时保留原行为。

预览横向实线在生成后逐行对齐实际笔画下沿，包含仿真变化、标点及公式；公式占用多行时不显示穿过公式的中间参考线。空行和尚未生成内容的参考线按计算字高定位。实线与可写范围虚线框均只用于预览，不进入 G-code。参数为 `line_sizing: "rows" | "size"`、`line_looseness: 1..4`；返回元数据包含最终 `rows`、`size`、`pitch` 和 `row_guides`。

汉字及中文标点采用字体自身的汉字参考框缩放，不再套用较小的英文大写字母基准。在行数/字高联动模式中，普通文字每行只占一个行位。需要适配超高字形或较强仿真时，在测宽前统一确定当前内容块的尺寸，手动换行不会触发新的缩放决定；不再单独缩小某一行，也不在换行后改变字形宽度。英文单词、常见连字符词和数字单位在能放入一整行时优先保持完整；手动换行和空行保留。高分式等公式仍按实际高度保留多个行位。

新版页面默认按实际笔画范围排笔记（`line_placement: "ink"`），无需“允许字重叠”开关。松紧滑块给出基准行距；实际排版保留请求的中文字高和英文字高，按每行已生成的真实路径（含仿真和补字）测量上下界。正文仅在相邻墨迹可能相碰时局部增距，公式上下保留稍宽的安全留白；留白精确到毫米，不强制增加整行。边界放不下就续页，固定分页则报溢出。基准行数不保证每页的实际行数；预览会显示本页实际行数。空行、显式分页符及公式形状保留；高亮和参考线只显示在预览中。`line_layout` 返回每行实际上下界、排布位置和增加的间隙，用于核对结果。旧 API 不提供 `line_placement` 时保留旧行位布局；旧 `allow_overlap` 请求也会保护公式，避免公式与前后正文覆盖。

可选“智能均衡中英大小”（`smart_balance`，默认关闭以兼容旧预设）。按代表字形的真实笔画测量中位高度，所选中文作用域字体按权重提供共同基准，分别校准每个字体的字母和数字，使大写字母及数字的典型高度约为汉字的 90%；小写保留该字体相对大写的比例。没有可测量汉字时使用名义字高基准。自动缩放限制在 35–140%，`letter_scale`、`digit_scale`（50–150%，默认 100）分别叠加手动微调，原有 `latin_size` 继续决定笔记的英文字高基准。均匀缩放保留宽高比及笔画，补字采用替代字体自身的测量，公式按调整后的字形重新排布。表格以调整前的格内占比为基准，避免自动填满格高抵消缩小，放大仍限制在格内。预设、模式草稿及文档 JSON 保存这些选项；预览元数据 `font_balance` 记录实际使用字体的缩放、样本数及参考来源。

首页先选择笔记或表格模式。字体组合预设继续共用，**排版预设按模式独立保存**；原笔记预设仍可读取，并补上新参数的默认值。切换模式保留各自尚未保存的当前参数。预设保存在当前浏览器、当前站点；“保存整份文档”可下载包含内容、两种模式当前排版、字体选择及坐标的 JSON，在另一浏览器载入。

## 内容与分页

- 文档可以添加、删除和切换预设内容页；每个预设内容页从新纸开始。
- 自动续页：根据实际字宽、公式高度、每页行数或格子容量分页。
- 固定每页内容：任何预设内容页溢出都明确报错，不截断内容。
- `\newpage`、`\pagebreak`、换页符 U+000C 均可显式分页。
- 开头空行、开头空格保留其位置；行末的单个换行符不额外生成空白页。英文自动换行时可能移除作为断行位置的空格。
- 所有页面生成后，右侧切换输出页；输出页与左侧预设内容页可能不是一一对应。
- 空白预设页仍可预览、下载，不能启动空白书写任务。
- 每页对应独立任务 ID、预览、元数据和 G-code。页面切换清除原点确认，已经提交的页面不会在前端重新启用。完成一页后换纸、选择下一页并重新确认原点；没有自动送纸或自动连续启动。
- ZIP 下载包含 `manifest.json` 与逐页 `.gcode`、`.svg`、`.json`。下载与执行都使用缓存结果，不重新随机排版。

混排在每张实际输出页内协调重复字符：仅使用作用域适用、权重大于零且具有可绘制字形的所选字体。同字出现次数不多于可用字体数时不重复字体；超过时使用全部可用字体，按实际墨迹中心的二维毫米距离尽量增大最近同字同字体的间隔。分散优先于原概率，权重用于等价空间分组的字体选择，不能再把权重理解为每个重复字符的精确频率。小组（最多 10 次）穷举无标签分组，大组使用距离冲突图着色；大组为有界的近似优化，不承诺组合优化的全局最优。换字体后重新测宽、换行、分页，按新的实际页重新核对；分页震荡时保留页面边界继续拆分，避免输出不满足字体多样性的页面。正文和公式内字形一起参与，缺字仍按最近字体补入，不为分散而改用更远的补字字体。`glyph_occurrences` 保存最终字形、字体及纸面范围，`repeat_distribution` 保存重复字使用字体数和最近同字体距离。预览展示本页分散结果；下载和写入使用这些已确定的路径。

新文档最多 30000 个输入字符、100 个预设页、100 个输出页；单页最多 20 万点，整份文档最多 200 万点。内存缓存按整份文档移出，最多 8 份且合计最多 200 万点；磁盘中的预览、G-code、元数据与页序索引持续保留。内存移出和后端重启不会使已生成页面失效，后续页可按原任务编号继续写入、单页下载或按原顺序整份打包，无需重新生成或重新随机字体。旧版本已保存的页面也可直接从三个原始文件恢复；旧版本尚未保存整份文档索引的预览，可继续逐页写入和单独下载。恢复时核对 G-code 哈希及指令数，文件缺失或损坏会明确报错。旧版不带 `layout_mode` 的单页 API 保持原行为及 3000 字限制。

## 笔记排版与中文标点

页面四边边距内按可写宽度换行，每页行距 = 可写高度 / 行数。超过一个行位高度的公式会占用多个行位。内容使用字体公共基线排布，不会把每页第一个非空字重新移动到纸顶。

`punctuation_width` 表示中文标点的最小占位宽度，单位为字高倍数，范围 0–2，默认 0.8。通过留白加宽，不横向拉伸笔画。自动换行尽可能将常见闭标点与前字一起、开标点与后字一起移动；窄到无法容纳这一组合时明确提示调整宽度或字高。

## 表格模式

表格是参考图中的逐字方格，普通字符每字占一格，空格占格，换行进入下一格行；不属于带合并单元格的数据表格编辑器。

可设置行数、列数、行间隔、列间隔、格内边距、字高占可用格高百分比：

```text
格宽 = (可写宽度 - (列数 - 1) × 列间隔) / 列数
格高 = (可写高度 - (行数 - 1) × 行间隔) / 行数
```

内置 A4 表格预设的可写范围为 157 × 215 mm，20 行 × 20 列、行间隔 2.9 mm、列间隔 0，对应格宽 7.85 mm、格高 7.995 mm。字形保持比例并居中，过宽字符会缩小到格内。公式作为整体按格高缩放，并自动占用多个连续格，不会拆成 LaTeX 命令文字。

默认格线仅是预览参考，适用于纸上已有格子的情况；勾选“实际绘制格线”才将格线加入 G-code。共享格边只绘制一次。表格模式以格内比例决定字号，笔记的字高和字间距不直接决定格内尺寸。

## TXT、Markdown 与基础公式

“导入 TXT / Markdown”读取 UTF-8 文件并替换当前预设内容页，保留其他页；读取、格式和长度校验成功后才替换，取消或导入失败不会清空原文。支持 `.txt`、`.md`、`.markdown`；文件最多 512 KiB。格式选择对整份文档生效。Markdown 只将标题、粗体及链接转为普通文字，保留换行与公式；不提供完整 Markdown 页面渲染或图片嵌入。

```text
行内：圆的面积 $S = \pi r^2$。

独立公式：
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

\newpage

$$\int_0^1 x^2 dx = \frac{1}{3}$$
```

支持 `$...$` / `\(...\)` 行内公式，`$$...$$` / `\[...\]` 独立公式；普通文字中的美元符用 `\$` 转义。支持：

- 分式与根式：`\frac`、`\dfrac`、`\tfrac`、`\sqrt{x}`、`\sqrt[3]{x}`、`\binom`、`\dbinom`、`\tbinom`。独立公式中的普通分式保持较大的字形；`\tfrac` 强制使用紧凑分式。
- 上下标：`^` / `_`、`\limits` / `\nolimits`、`\substack`。独立公式中的 `\sum`、`\prod`、`\lim` 等默认将上下限居中放在主体上下；积分默认使用侧边上下限。
- 括号：成对的 `\left ... \right` 随内容高度拉伸，支持圆、方、花、尖括号、单/双竖线、取整括号、斜线及不可见侧 `.`；`\big`、`\Big`、`\bigg`、`\Bigg` 及其 `l` / `r` 形式可指定高度。
- 矩阵与多行：`matrix`、`pmatrix`、`bmatrix`、`Bmatrix`、`vmatrix`、`Vmatrix`、`smallmatrix`、`cases`、`aligned`、`split`、`gathered`、`array`、`equation` / `equation*` 环境。列用 `&` 分隔，行用 `\\` 或 `\cr`；`array` 支持 `l` / `c` / `r` 列格式；行距可用 `\\[2pt]`、`\\[0.5em]`、`ex` 或 `mm` 追加。
- 标记与注释：`\bar`、`\overline`、`\underline`、`\vec`、`\overrightarrow`、`\overleftarrow`、`\hat`、`\widehat`、`\tilde`、`\widetilde`、`\dot`、`\ddot`、`\overbrace`、`\underbrace`、`\overset`、`\underset`、`\stackrel`、`\boxed`。
- 函数：`\sin`、`\cos`、`\tan`、`\cot`、`\sec`、`\csc`、反三角函数、双曲函数，以及 `\log`、`\ln`、`\lg`、`\exp`、`\lim`、`\limsup`、`\liminf`、`\max`、`\min`、`\sup`、`\inf`、`\det`、`\dim`、`\gcd`、`\ker` 等。
- 符号：全部小写希腊字母、常用大写希腊字母；`\sum`、`\prod`、`\int`、`\iint`、`\iiint`、`\oint`、`\bigcup`、`\bigcap`；关系、集合、逻辑与箭头，如 `\approx`、`\equiv`、`\in`、`\notin`、`\subseteq`、`\cup`、`\forall`、`\exists`、`\Rightarrow`、`\Leftrightarrow`；`\not`、`\nabla`、`\partial`、`\hbar`、`\angle`、`\prime`、`\dots` / `\cdots` / `\vdots` / `\ddots` 等。
- 文字与间隔：`\text` / `\textrm` / `\textnormal` / `\mbox` 保留文字空格；`\operatorname` / `\operatorname*` 自定义算子；`\,`、`\:`、`\;`、`\quad`、`\qquad`、`\!`（负间隔）、`\enspace`；`\phantom` / `\hphantom` / `\vphantom` 保留空白尺寸。
- `\mathrm`、`\mathbf`、`\mathit`、`\mathsf`、`\mathtt`、`\mathcal`、`\mathbb`、`\boldsymbol` 等样式命令接受内容并继续使用所选单线字体，不模拟粗体、双线黑板体或书法体。`\displaystyle` / `\textstyle` 切换分式和算子排版。

```latex
$$\begin{cases}
\sqrt[3]{x} & x \ge 0 \\
-\sqrt{-x} & x < 0
\end{cases}$$

$$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

$$\begin{aligned}
y &= \frac{x+1}{2} \\
z &= \left[\frac{a}{b}\right]^2
\end{aligned}$$

$$\sum_{\substack{i=1\\j>0}}^n i = \frac{n(n+1)}{2}$$
```

公式生成真实毫米单线笔画，保留缺字回退标记、字体混排和同页重复字分配信息。所选字体缺少 ASCII 字母、数字时，可使用仓库自带的原创单线演示字体回退；数学符号与可伸缩括号使用原创几何笔画。公式整体保持不可拆分，笔记排版按实际笔画范围避让；表格模式仍按格高整体缩放。

这是受限的公式引擎，不执行 TeX、宏、文件读取、外部包或任意代码；不支持自定义宏、自动编号、跨页公式及任意 TeX 表格列格式。每个公式最多 1000 个字符、嵌套最多 12 层，表格最多 24 行、12 列、累计 144 个单元格。不支持的命令、不匹配的环境、未闭合的分隔符或超宽/超高公式会明确报错，不会静默丢弃内容。

## 业务 API

`POST /api/preview` 的新文档示例：

```json
{
  "layout_mode": "notebook",
  "pagination": "auto",
  "font_id": "从 /api/fonts 获取",
  "pages": [{"text": "第一预设页\n$x^2$"}, {"text": "第二预设页"}],
  "width": 210, "height": 297,
  "margin_top": 30, "margin_bottom": 30,
  "margin_left": 30, "margin_right": 30,
  "rows": 20, "size": 5, "spacing": 0.9,
  "punctuation_width": 0.8,
  "input_format": "plain",
  "seed": "repeatable"
}
```

表格模式使用 `"layout_mode":"grid"`，并可附加：

```json
{"grid":{"columns":20,"row_gap":2.9,"column_gap":0,"size_percent":80,"padding":0.3,"draw_lines":false}}
```

响应增加 `document_id`、`page_count`、`pages`；每页包含原有 `job_id`、`metadata`、`svg`。原顶层单页字段仍保留，指向第一页。

- `GET /api/jobs/<job_id>/gcode`：当前单页下载。
- `GET /api/documents/<document_id>/archive`：整份 ZIP。
- `POST /api/start`：仍使用单页 `job_id` 和 `origin_confirmed:true`。
- `POST /api/coordinate-preview`：带 `layout_mode` 时返回对应笔记/表格参考页面，不需要连接控制器。

C++ 控制端与串口协议没有改变。
