# 服务器预设

字体组合、笔记排版和表格排版预设由业务后端持久保存，同一业务后端的浏览器和设备共用。当前没有用户账户隔离；共享范围与现有业务服务一致。页面打开或刷新后读取服务器数据，最后选择仍按浏览器保存。

数据文件为 `--jobs-dir/.presets.json`，独立于发布目录。使用线程锁、文件同步和原子替换；写入失败不更新内存或提示保存成功。每类保存带修订号，过期页面提交会被拒绝，需刷新后重试。

- `GET /api/presets` 返回 `groups`，包含 `layout`、`grid`、`font` 三类，每类为 `{revision, presets}`。
- `POST /api/presets` 接收 `{kind, revision, presets}`，用于该类预设新增、修改、删除及撤销；每类最多 500 个。接口沿用现有 Host、Origin 和访问令牌检查。
- `POST /api/presets/migrate` 接收 `{groups: {layout?: {presets, selected}, grid?: ..., font?: ...}}`，按原始条目内容指纹去重。冲突编号生成新编号，重名添加迁移后缀；返回映射后的选择。迁移记录持久保存，之后删除的已迁移条目不会因旧浏览器再次打开而复活。

打开页面时自动迁移该站点的旧 `plotter.layout-presets.v1`、`plotter.grid-presets.v1`、`plotter.font-presets.v1`，原存储保留为备份，不再作为预设主存储。缺少字体的预设仍完整保留，并由现有界面标注缺少字体。服务不可用时保存明确失败。

新部署的自定义预设为空。仓库不包含个人排版、字体组合、浏览器存储导出或迁移备份；A4 等通用内置预设保留。部署时使用独立任务目录，勿复制其他实例的运行数据。
